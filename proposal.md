## Software: SciPy

*SciPy is a open sourced python library used for scientific and numerical computing. It provides various numerical algos for problems like optimization, root finding, integration, iterpolation, etc. A plethora of things we attack every day during class. for this project i plan to focus mainly on root finding algorithms in scipy.optimize because they relate directly to are classes topics. (convergence, accuracy, computational cost and stability) *
